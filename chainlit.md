## Getting Started

Simply type a message below and press **Enter** to interact with the agent.

### 🔧 Configuration
Ensure your provider credentials are set correctly in `.env`:
```
LLM_API_KEY=your-key
LLM_BASE_URL=https://api.featherless.ai/v1
LLM_MODEL=deepseek-ai/DeepSeek-R1-0528
```
